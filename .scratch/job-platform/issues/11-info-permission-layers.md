# 11 — L1/L2 信息权限分层 + HR 查看求职者详情

**What to build:** 实现信息权限分层。L1 公开信息（无需登录）：脱敏姓名、头像、技能标签、工作年限、期望职位。L2 登录可见（仅认证 HR）：工作经历详情、证书列表。未认证 HR 只能看到 L1。

**Blocked by:** 05 — HR 搜索求职者，10 — 管理员审核企业

**Status:** ready-for-agent

- [ ] profile-service API：L1 公开信息端点（无需 JWT），返回脱敏姓名（张**）、头像 URL、技能标签列表、工作年限、期望职位
- [ ] profile-service API：L2 详情端点（需 JWT + 认证 HR 角色），返回工作经历详情、证书列表
- [ ] 权限中间件：未认证 HR 访问 L2 端点返回 403
- [ ] 前端：求职者详情页分为「公开信息区」和「详细信息区」
- [ ] 前端：未登录用户访问详情页只看到 L1 信息
- [ ] 前端：认证 HR 登录后看到 L1 + L2 完整信息
