# 前端 - 管理员后台

**Status:** needs-triage  
**Type:** task  
**Blocked by:** 01, 02, 03, 04

实现管理员后台前端，使用 Ant Design Pro，同一 React 项目（`/admin/*` 路由）。

## 需求

- React + Ant Design Pro（同一项目，`/admin/*` 路由）
- JWT 认证，角色判断为 admin 才可访问
- 页面：
  - 企业认证审核（营业执照列表、审核通过/拒绝）
  - 举报管理（举报列表、审核处理、隐藏违规评价）
  - 用户管理（用户列表、封禁/解封）
  - 数据看板（注册数、认证企业数、简历请求数等 MVP 指标）
- 统一 JWT 鉴权

## 验收条件

1. 管理员登录后只能访问 `/admin/*` 路由
2. 可审核营业执照（通过/拒绝）
3. 可处理举报（隐藏违规评价）
4. 可封禁/解封用户
5. 数据看板展示 MVP 核心指标
