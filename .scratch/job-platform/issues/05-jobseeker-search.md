# 05 — HR 搜索求职者（按技能 + 经验 + 期望职位）

**What to build:** HR 输入技能关键词，搜索匹配的求职者列表，支持按经验年限和期望职位筛选。搜索结果按已验证技能数排序（MVP 阶段验证数为 0 则按经验年限排序）。使用 PostgreSQL 全文搜索。

**Blocked by:** 04 — 技能标签管理

**Status:** ready-for-agent

- [ ] profile-service 实现求职者搜索 API：支持技能关键词匹配（tsvector/tsquery）、经验年限范围筛选、期望职位筛选
- [ ] 排序策略：已验证技能数量 > 技能匹配度 > 经验年限
- [ ] 搜索结果仅返回 L1 公开信息字段（脱敏姓名、技能标签列表、工作年限、期望职位、GitHub 高星项目占位）
- [ ] 前端（HR 端）：搜索页面，包含技能关键词输入框、经验年限范围选择器、期望职位筛选
- [ ] 前端：搜索结果列表展示求职者卡片（脱敏姓名、技能标签、经验、期望职位）
- [ ] 前端：点击求职者卡片跳转到详情页（详情页 L1/L2 权限在后续 ticket 实现）
