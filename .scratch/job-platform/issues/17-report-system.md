# 17 — 举报机制 + 管理员处理

**What to build:** 任何用户可以对违规评价（恶意评价、侮辱性内容、不实信息）发起举报，管理员在后台审核，确认违规则隐藏该评价。举报处理结果通知举报人。

**Blocked by:** 13 — HR 评价求职者，15 — 求职者评价公司

**Status:** ready-for-agent

- [ ] rating-service 实现 Report 表（id, reporter_id, target_type, target_id, reason, status）
- [ ] rating-service API：用户对评价发起举报（理由：恶意评价/侮辱性内容/不实信息）
- [ ] rating-service API：管理员查询举报列表、审核通过/拒绝
- [ ] 审核通过后隐藏被举报评价（is_hidden = true，前端不展示）
- [ ] 审核通过后通知举报人处理结果
- [ ] 前端（通用）：评价旁展示「举报」按钮
