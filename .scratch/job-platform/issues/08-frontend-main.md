# 前端 - 求职者/HR 端

**Status:** needs-triage  
**Type:** task  
**Blocked by:** 01, 02, 03, 04, 05, 07

实现 React 前端（求职者/HR 端），响应式 + PWA。

## 需求

- React 18 + TypeScript + Vite + Ant Design
- 响应式布局 + PWA（vite-plugin-pwa）
- 页面：
  - 登录/注册页（OAuth + 手机号）
  - 求职者个人主页（个人信息、技能标签、工作经历、证书、GitHub 项目）
  - HR 搜索页（按技能/经验/期望职位搜索，结果列表）
  - 求职者详情查看页（L1/L2 信息分层展示）
  - 简历请求管理页（发起/处理请求）
  - 评价列表页（标签式展示）
  - 通知中心（未读列表、标记已读）
  - 公司浏览页（按行业/规模浏览、「感兴趣」按钮）
  - 简历上传页（PDF 上传）
- 状态管理：React Query（服务端）+ Zustand（客户端）
- 统一 JWT 认证，Axios 拦截器

## 验收条件

1. 所有页面响应式适配移动端
2. PWA 可安装
3. JWT 自动刷新
4. 信息分层：L1 公开、L2 登录可见、L3 授权可见
5. 搜索支持技能标签选择 + 经验筛选
