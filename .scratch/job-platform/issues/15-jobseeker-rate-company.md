# 15 — 求职者评价公司（标签式）+ 公司评价统计展示

**What to build:** 求职者可以对已认证公司提交职业规范性评价（正面标签：招聘规范/承诺兑现；负面标签：招聘不规范/承诺未兑现/面试不当），公司页面展示评价统计（规范/不规范次数，不计算百分比）。

**Blocked by:** 02 — Auth 登录，09 — 企业信息

**Status:** ready-for-agent

- [ ] rating-service 实现求职者 → 公司的评价 API（正面标签/负面标签 + 可选文字评论）
- [ ] 评价权限：需手机号验证通过的求职者，每天最多 5 次评价
- [ ] 同一求职者对同一公司只能评价一次（可更新最后一次评价）
- [ ] 评价不可自行删除
- [ ] company-service API：获取公司的评价统计（正面标签次数/负面标签次数）
- [ ] 前端（求职者端）：公司详情页展示评价统计和最近评价列表
- [ ] 前端（求职者端）：公司详情页增加「评价该公司」按钮，标签选择 + 可选评论
- [ ] 前端：评价统计展示为「👍 规范 X 次 / 👎 不规范 Y 次」，非百分比
- [ ] 前端：HR 端不显示公司评价功能
- [ ] 测试：求职者可提交公司评价
- [ ] 测试：每天超过 5 次评价被拒绝
- [ ] 测试：同一求职者对同一公司重复评价更新最后一次
