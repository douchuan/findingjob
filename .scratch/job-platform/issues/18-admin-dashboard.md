# 18 — 管理员数据看板（注册数/交互数/MVP 指标）

**What to build:** 管理员在后台看到平台核心数据指标：求职者注册数、认证企业数、简历请求次数、评价数等，用于追踪 MVP 成功标准。

**Blocked by:** 10 — 管理员审核企业

**Status:** ready-for-agent

- [ ] 后端 API：聚合查询 — 求职者注册总数、认证 HR/企业数、简历请求总数（approved/pending/rejected 分类）、评价总数、举报处理数
- [ ] 前端（管理员后台 `/admin/*`）：数据看板页面（Ant Design Pro 统计卡片）
- [ ] 前端：展示 MVP 目标进度（100 求职者 / 10 企业 / 50 简历请求）
- [ ] 前端：趋势图表（近 7 天注册数、交互数，简单折线图）
- [ ] 测试：数据看板数字与实际数据库记录一致
